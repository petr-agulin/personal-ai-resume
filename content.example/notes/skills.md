## SQL

I learned SQL at Corvid Analytics, where I queried our own product data in PostgreSQL every day to see how customers used the dashboard builder. Today I write queries that join five or six tables, use window functions for cohort and retention analysis, and check the numbers before I bring them to a planning meeting. I don't build data pipelines myself; for that I work with a data engineer.

## API design

At Ledgerline I own the public API as a product. I write the specifications with the engineers, review every new endpoint for naming and error handling, and keep a changelog that partners actually read. I introduced versioning with a twelve-month deprecation window after a breaking change hurt three partners in my first year.
